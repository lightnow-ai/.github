# LightNow profile banner

Updated 2026-11-09 to follow the public lightnow.ai website.

- Editable vector: `lightnow-hero.svg`; raster export: `lightnow-hero.png`, 1600 × 640.
- Logo: canonical LightNow v6, reused unchanged from Registry-UI's
  `public/assets/logo/logo.svg`.
- Typography: outlines from the website's Schibsted Grotesk regular and bold
  fonts (SIL Open Font License); no font binary is embedded.
- Website colors: forest `#0b100e`, ink `#eef5ed`, muted `#a6b8aa`,
  rules `#34463a`, lime `#b9f28e`.
- Headline and supporting line: https://lightnow.ai/.
- Deterministic vector composition, exported through resvg-py. No generated
  bitmap artwork, customer logos or product mockups.
- Exact-size and reduced PNG inspected; all text, including descenders,
  fits within the image. The README supplies the image's text alternative.
